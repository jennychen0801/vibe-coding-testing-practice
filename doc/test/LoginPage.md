**範例輸入**：Email 輸入 `invalid-email`, 密碼輸入 `ValidPass123`，點擊登入
**期待輸出**：畫面提示「請輸入有效的 Email 格式」，且不會呼叫登入 API

## [x] 【function 邏輯】密碼長度驗證失敗
**範例輸入**：Email 輸入 `test@example.com`, 密碼輸入 `short1`，點擊登入
**期待輸出**：畫面提示「密碼必須至少 8 個字元」，且不會呼叫登入 API

---

## [x] 【function 邏輯】密碼格式驗證失敗
**範例輸入**：Email 輸入 `test@example.com`, 密碼輸入 `12345678`（無英文）或 `abcdefgh`（無數字），點擊登入
**期待輸出**：畫面提示「密碼必須包含英文字母和數字」，且不會呼叫登入 API

---

## [x] 【驗證權限】已登入狀態下訪問登入頁
**範例輸入**：`isAuthenticated` 狀態為 true
**期待輸出**：自動導向至 `/dashboard`

## [x] 【驗證權限】顯示登入過期提示
**範例輸入**：`authExpiredMessage` 有值 (例如「登入已過期」)
**期待輸出**：畫面顯示登入過期的錯誤訊息，且呼叫 `clearAuthExpiredMessage` 清除該狀態

## [x] 【Mock API】登入載入中狀態顯示

---

## [x] 【Mock API】登入成功後導向
**範例輸入**：API 請求成功回傳
**期待輸出**：成功導向至 `/dashboard`，無錯誤提示
